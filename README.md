# Yoannis Tamayo Movement · sitio web

Sitio de **Yoannis Tamayo & Anita**: formaciones, talleres, clases privadas, clases online a nivel global y la academia de formación online.

## Ver el sitio
Abre `index.html` en el navegador. Es un solo archivo HTML, sin instalación ni dependencias (solo carga Google Fonts).

Para publicarlo: **Settings → Pages → Deploy from a branch → `main` / root**.

## Estructura
```
index.html   # todo el sitio (HTML + CSS + JS)
img/         # fotos y logo (versiones para fondo claro y oscuro)
```

## Qué editar (dentro de `index.html`, bloque `<script>`)
| Dato | Dónde |
|---|---|
| Próximas formaciones | arreglo `FORMS` |
| Calendario / agenda | arreglo `EVENTS` |
| Lecciones de la plataforma online | arreglo `VIDS` |
| Estilos (afro, rumba, son…) | arreglo `STY` |
| Videos de YouTube | sección `#videos` (enlaces `watch?v=`) |
